# エディタ機能仕様

## 画面構成
上部：プロジェクト名、保存、読込、Undo/Redo、プレビュー、出力。
左：ページ一覧、レイアウトテンプレート、AV部品ライブラリ。
中央：キャンバス、選択枠、ガイド、ズーム。
右：選択要素のプロパティ（位置・サイズ・文字・色・状態・アクション）。

## 操作
- パレットからドラッグで配置、クリック選択、ドラッグ移動、ハンドルで拡縮。
- X/Y/W/Hを数値入力可能。最小サイズを部品ごとに設定。画面外配置は原則禁止。
- 8pxグリッドへのスナップ切替、等間隔/端揃えガイド。矢印キーで1px移動、Shift+矢印で8px移動。
- Delete削除、Ctrl/Cmd+Z Undo、Ctrl/Cmd+Shift+Z Redo、Ctrl/Cmd+D複製。
- 要素の重なり順（前面/背面）とロック。ページ複製・名称変更・削除。最終1ページは削除不可。
- キャンバスのズームは表示倍率のみ変更し、保存座標には影響しない。
- プロパティ変更は操作単位で履歴化。ドラッグ中の多数のポインターイベントは一つのUndo単位に統合。
- 初期段階では複数選択、グループ化、レスポンシブ自動配置、複雑な制約レイアウトは対象外。

## 保存
ブラウザローカルでの作業中自動保存は追加可能。ただしJSONファイルとして明示的に保存・読込できることを必須とする。
