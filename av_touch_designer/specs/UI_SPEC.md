# UI・テーマ・テンプレート仕様

## 基本原則
装飾線・過度なグラデーション・不要な影を避け、可読性とタッチ操作を優先。テーマとレイアウトは別管理。ブランドロゴやメーカー製品画像の無断同梱をしない。

## テーマ（MVP）
Modern Dark（標準）、Minimal Light。Premium、Professional AVは後続フェーズで追加。
テーマトークン：背景、面、文字、補助文字、アクセント、境界、危険、成功、角丸、影、フォント、余白、選択状態。

## レイアウトテンプレート（MVP）
Blank、Standard Meeting Room（入力切替+音量+電源）、Presentation Room（映像ソース+表示先+音量）。後続でCamera Focus、Multi-Zone Audio。

## コンポーネント（MVP）
- Button: ラベル、アイコン、選択/無効/押下状態、アクション。
- SourceSelector: 複数候補から単一選択、選択中表示。
- Volume: スライダー、数値、ミュート切替（0〜100の模擬値）。
- Label: 文字、整列、サイズ。
- Panel: 背景付きの視覚的グループ（内部要素の親子座標はMVPでは不要）。
- Navigation: ページ移動ボタン。

## 後続コンポーネント
PTZ方向操作、ズーム、カメラプリセット、照明シーン、プロジェクター操作、画像表示。

## 基準画面サイズ
1920×1080、1280×800、1024×768、カスタム（幅/高さの上限・下限をバリデーション）。最初の画面は1280×800を推奨初期値とする。

## アクセシビリティ
タッチ対象は原則44 CSS px以上を推奨し、色だけに依存しない選択表現を用意。コントラスト・文字切れを確認。
