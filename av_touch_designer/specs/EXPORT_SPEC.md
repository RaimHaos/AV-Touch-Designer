# 出力仕様

## HTML
- `index.html`を入口とするZIP形式の独立パッケージ（必要なCSS/JS/画像を同梱）。ネットワーク接続なしで動作。
- エディタのツールバー、選択枠、編集用依存関係、保存・編集機能は含めない。
- 基準キャンバスを縦横比維持で画面内に収める。余白は背景色で表示。ブラウザ全画面表示を想定。
- モック用アクション・ページ遷移・状態変化を維持する。実機制御は含めない。
- ファイル直開き（file://）でも動作するよう、ES moduleの外部読み込み制約を避ける配布ビルド方式を採用し、実ブラウザで確認する。
- HTML内部にデータを埋め込む場合は安全にシリアライズし、`</script>`等で構造が壊れないようにする。

## PNG
- 現在ページの基準解像度で書き出す。プレビュー初期状態を既定とし、現在の模擬状態で出力する場合は選択可能にするのは後続。
- 文字、アイコン、背景、境界、選択状態を反映。編集ガイドは含めない。
- DOMキャプチャ方式はフォント・CSS・SVGの再現性を自動テストで確認。必要なら専用キャプチャ手法へ切替。

## 検証
エディタ表示・プレビュー・HTML出力・PNGの差異を代表画面で比較する。
