# テスト仕様

## 単体テスト
スキーマ検証、座標クランプ、リサイズ最小値、ID一意性、Undo/Redo、テーマトークン、アクション実行、ページ参照、JSON往復。

## 統合テスト
テンプレートから生成→編集→保存→再読込→プレビュー→HTML/PNG出力。

## E2E
PlaywrightでChrome系ブラウザを基準に、ドラッグ移動、リサイズ、数値入力、ページ切替、Undo、キーボード操作、ZIP展開後のHTML表示を検証。

## 品質基準
- 実装対象の必須操作は自動テストで再現できる。
- JSONの保存→再読込で情報欠落がない。
- HTMLはネットワークを遮断して動作し、編集UIを含まない。
- 代表画面の1280×800、1920×1080、1024×768で文字切れ・重なりを目視確認。
- 不正JSON、参照切れ、画像上限超過時にクラッシュせず説明を表示。
- Windows Chrome/Edgeの現行安定版を優先対象とする。実際に試験したバージョンを報告。

## 非機能
代表的な50要素/5ページのサンプルで編集操作が実用的に応答すること。数値目標はPhase 1の計測後に決定し、未計測の性能保証はしない。
