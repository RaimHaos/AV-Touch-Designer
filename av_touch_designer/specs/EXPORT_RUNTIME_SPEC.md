# HTML/PNGエクスポート詳細

## HTML
出力ZIP直下にindex.html、必要な相対CSS/JS/静的アセット。ネットワーク接続なし、file://直開きで動作。JSはES moduleを直接参照せず、通常scriptとしてバンドルし、動的import/fetch依存を作らない。外部CDN、フォント、画像、API、WebSocket、analyticsを含めない。編集ツールバー、履歴、プロパティUI、編集用依存を含めない。

同一ProjectRendererとRuntimeEngineを編集アプリのプレビュー/出力ビルドで共有。基準キャンバスをCSS transformで等比contain、中央配置、余白はテーマ背景色。タッチで画面スクロールを起こさない。リロードで初期ページ/状態。タップ・長押し・モーダル・状態表示・キーボード代替を一致させる。フルスクリーンはブラウザ側の操作に依存し、アプリから強制しない。

プロジェクト埋め込みはscript終端/特殊文字を安全にエスケープ。外部入力をinnerHTMLへ直接渡さない。`file://`環境のブラウザ制約はWindows Chrome/Edgeで実検証し、制約があれば説明と代替配布方式を報告。

## PNG
選択ページを基準解像度で初期状態として出力。編集枠/ガイド/ポインター表示なし。フォント/アイコン読み込み完了後にキャプチャ。背景、文字、SVG、境界、選択状態を確認。透過PNGはMVP対象外。出力失敗はエラー表示し、空白画像を成功扱いしない。

## 一致検証
代表5テンプレートのプレビュー/HTML/PNGを比較。操作はPlaywrightでローカルZIP展開後に試験し、外部ネットワークを遮断。解像度1280×800、1920×1080、1024×768で目視/スクリーンショット確認。
