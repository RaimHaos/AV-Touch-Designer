# 実装詳細・確定補足（2026-11-10）

本書は既存仕様の曖昧な箇所を補完する。矛盾時は本書を優先し、変更時はDECISIONS.mdにも記録する。

## 1. MVPの操作単位
- 新規作成→テンプレート選択→テーマ選択→部品追加→配置調整→アクション設定→プレビュー→JSON保存→HTML/PNG出力。
- エディタはPC用。出力モックはタッチ/マウス両対応。
- 画面中央のキャンバスは論理座標で描画。ズーム・スクロールは表示のみ変更。
- 選択中要素の枠は編集モードにのみ表示。Escapeで選択解除。キャンバス空白クリックで選択解除。
- ドラッグ開始は4px以上のポインタ移動で判定。ドロップ時に一度だけ履歴を確定。スナップは初期ON、8px。Alt押下中は一時的にスナップ無効。
- リサイズは四隅と四辺の8ハンドル。幅・高さは正数。要素の最小寸法を優先。キャンバス外には出さない。
- 編集モードでのクリックは要素選択のみで、アクションを発火させない。
- 複数選択、グループ化、ネスト、回転、アニメーション編集はMVP対象外。

## 2. 基本コンポーネントの表示仕様
- Button: text/icon、variant(default/primary/danger)、stateKeyと選択値を参照して選択状態を描画。disabled時はアクション無効。
- Label: プレーンテキスト。折り返し可。長文が枠外にはみ出ないようoverflowを制御。
- Panel: 背景と見出しを持つ視覚的領域。子要素は含まない。背景として他要素の背面に置く。
- Navigation: Buttonと同じ外観系で、navigateのみを扱う。
- SourceSelector: props.options=[{label,value,icon?}]、props.stateKey。1つの状態キーに対応する選択群を内部描画し、クリックで該当valueを選択。オプションは1〜8個。選択中は色とアイコン/枠で識別。
- Volume: props.stateKey, muteStateKey, label。値は整数0〜100、ミュートはboolean。スライダー操作で音量を更新し、ミュート切替は音量値を保持する。音量0とミュート状態は別概念。
- すべての要素に共通: id/type/x/y/width/height/zIndex/locked/props/action。複合部品内部の子ボタンは独立要素IDを持たない。

## 3. プレビューの意味論
- 初期状態はproject.initialStateのコピー。プレビュー再入場でリセット。ページ遷移では状態保持。
- none: 何もしない。navigate: pageIdへ移動。toggle: booleanのみ反転。select: stateKeyへvalue代入。setValue: number/boolean/stringを型一致で代入。
- 初期状態に存在しないキー、型不一致、存在しないページは編集時エラー表示。プレビュー実行時は無視し、クラッシュさせない。
- SourceSelector/Volumeの内蔵操作はpropsのstateKeyを利用する。element.actionはnone固定とする（将来の複合アクションは別版）。
- 状態表示は、Buttonのprops.selectedWhen={stateKey,value}で判定。操作アクションと見た目を分離する。

## 4. 保存と復旧
- JSONはUTF-8で保存。読み込み前にschemaVersionと構造を検証し、不正時は既存編集中プロジェクトを保持。
- JSONのキー順は実装依存だが、保存→読込で意味上の完全一致を保証。
- undo/redoはプロジェクト編集のみ。プレビュー中の状態変化は履歴対象外。
- Undo履歴は最大100操作。新しい編集後はRedo履歴を破棄。ページ削除などの構造変更も1操作として扱う。

## 5. HTML/PNG出力の合格条件
- HTML ZIPはindex.htmlをルートに置き、相対パスでローカル表示。外部ネットワーク通信なし。CSPに抵触する不要な動的コード実行を行わない。
- HTML内に編集機能・編集依存パッケージ・開発用画面を含めない。ブラウザのリロードで初期ページ・初期状態に戻る。
- 画面サイズは論理キャンバス全体をcontainで表示し、アスペクト比を維持。タッチ操作で誤スクロールしない。
- PNGは現在ページを初期状態で、論理キャンバス寸法にて出力。画像生成前にフォント・画像ロードを待つ。失敗時はエラーを表示し、空画像を成功扱いしない。

## 6. セキュリティと制約
- 文字列をHTMLとして解釈しない。dangerouslySetInnerHTMLを使わない。アイコンは許可リストから選択。
- 任意のHTML/JS/CSS貼付け、外部URLからの画像読み込み、制御コマンド入力はMVPで不可。
- 初期のMVPは画像アップロード部品を提供しない（既存assetsフィールドは将来互換用）。
- project ID、page ID、element ID、stateKeyは安全な文字列として検証。アクション参照整合性を検証。
