# プレビュー動作仕様

- 編集モードとプレビューモードを明確に切替。プレビュー中は要素を移動・リサイズできない。
- アクション定義：none / navigate(pageId) / toggle(stateKey) / select(stateKey,value) / setValue(stateKey,value)。
- stateKeyはプロジェクト内の模擬状態キー。制御プロトコルやIPアドレスではない。
- ボタン選択、入力ソース切替、ミュート、音量変更、ページ遷移を画面内で再現。
- 状態はプレビュー開始時に定義済み初期値へリセット。ページ遷移では保持。
- 不正なページ参照・状態参照は編集画面に警告し、実行時には安全に無視する。
- タッチ/マウスで操作可能。キーボード操作も基本部品に対応。
- プレビューの模擬状態はプロジェクト構造を変更しない。
