# テストマトリクスと受入基準

|ID|対象|受入条件|
|---|---|---|
|T01|新規|5テンプレートが全参照整合で生成|
|T02|編集|移動・8ハンドルリサイズ・数値編集・Undo/Redoで期待値一致|
|T03|複数選択|Shift選択・整列・均等配置・一括移動・グループIDが保持|
|T04|テーマ|2テーマ切替で座標/文言/動作不変|
|T05|状態|排他選択、mute独立、volume範囲制約、ページ移動後保持|
|T06|長押し|成功、短押し、途中解除、領域外、pointercancel、blur、複数指、二重発火なし|
|T07|ポップアップ|開閉、確認/取消、背景遮断、Escape、フォーカス復帰|
|T08|カメラ|プリセットtapとhold登録、PTZ数値模擬|
|T09|電源|OFFはhold+確認、取消時不変、ONはtap|
|T10|保存|v2往復で意味一致、v1移行、未来版拒否|
|T11|安全|重複ID/参照切れ/型違反/巨大JSONを拒否し編集内容保持|
|T12|HTML|file://直開き、オフライン、エディタUIなし、動作一致|
|T13|PNG|論理解像度、文字/背景/アイコン欠落なし|
|T14|キーボード|Tab/Enter/Space、長押し代替、フォーカストラップ|
|T15|回帰|3解像度×2テーマ×5テンプレートの主要画面表示|

単体: Vitest。E2E: Playwright。時間テストはfake timerを使用。画像比較は許容差とOS/フォント差を記録し、機械的ピクセル完全一致を強制しない。未実施の検証は合格扱いにしない。
