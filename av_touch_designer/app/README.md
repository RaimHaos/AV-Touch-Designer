# AV Touch Designer 引継ぎ改修版

`codex/trial-download` の配布済みエディタを回収し、依頼された編集機能を追加した開発環境です。単体HTMLはインストール不要でChrome/Edgeから開けます。

## 起動・検証

Node.js 24 / npm 11、Python 3、Chromium。クラウド環境ではnpmキャッシュを書込可能な`/workspace/.npm-cache`へ指定します。既存チェックアウトを利用し、worktreeは作成しません。

```sh
cd /workspace/AV-Touch-Designer/av_touch_designer/app
npm ci --cache /workspace/.npm-cache
npm run typecheck
npm test
npm run build
npm start
```

サーバー起動後 `npm run test:e2e`。Chromiumは `/usr/bin/chromium`、別パスは `CHROMIUM_PATH` で指定。E2Eは独立HTMLの外部通信を遮断しても長押しが動くことを確認します。画像・ZIPは `test-results/` に生成します。

## 追加した操作

- プレビューの長押し中、上辺中央から時計回りにシアンの光が外周に蓄積し、一周で操作が完了。途中離脱・キャンセル・非表示・フォーカス喪失で中止。キーボード代替も維持。従来のoutline/bar/circle設定はこの版では外周表示に統一（noneは非表示）。HTML出力も同じ実装。
- 左側に「映像選択テンプレート」「音声テンプレート」「電源テンプレート」を配置。映像/音声はクリックすると数指定ダイアログが開き、1〜8を指定して追加。常時表示の数指定は廃止。映像と音声は別々のテンプレート。音声は全チャンネルに独立した音量・ミュートボタン（編集画面・プレビュー・HTML出力）を付属。画面に収まらない場合はダイアログ内で通知して追加しない。キャンセル/Escapeは無変更、フォーカスは起動ボタンへ復帰。電源は独立した状態と中央揃えのOFF確認ポップアップを一緒に追加。
- パネル単独の移動・サイズ変更では内部部品は追従しません。旧`responsive:true`も無効です。パネルと部品をCtrl＋クリックで明示的に複数選択すると一緒に移動・リサイズできます。
- Ctrl＋クリックで複数選択・選択解除（Macは⌘も対応）。キャンバスとレイヤー一覧の両方で使用。Shift＋クリックは追加選択しない。Shift＋矢印の8px移動とShift＋Tabは維持。
- 上部リボンを「ホーム／配置／デザイン／表示」に分割。コピー・貼付・複製・削除、整列・均等配置・グループ化、Fit表示を収納。右側は「基本／外観」と折りたたみ式「詳細設定」に分割。数値・テキストは基本、詳細プロパティは部品、イベントは動作で設定。隠した設定タブも状態を保持し、編集中の値をタブ切り替えで破棄しない。
- 横並び・縦並び・グリッドを選択部品に適用。間隔0〜200px、列数1〜20。要素配列の順序で配置。ロック部品は対象外。画面外になる配置は変更せず通知。
- 選択チェックマークは廃止し、選択中の背景・枠・文字色とaria-pressedで状態を表示。編集・プレビュー・出力HTMLで共通。
- 「起動ページテンプレート」でシステム待機画面を追加。初期表示をこのページにし、「システムを起動」で電源状態をONにして追加操作時の通常ページへ遷移。電源テンプレートを追加すると起動ページがなければ自動生成し、OFF確認の確定後に起動ページへ戻る遷移も設定。既存の起動ページは再利用し、名称を変更しても重複生成しない。電源を含む標準画面テンプレートも同じ循環動作。既存JSONは読込だけでは変更せず、起動ページまたは電源テンプレート追加でこの設定を適用。
- 操作UIはテーマに依存しない白基調へ固定。上部「デザイン」でパネルだけをダーク・シアン／ライト・ブルー／ネイビー／ウォームへ変更。配色と角丸を切り替え、JSON・プレビュー・HTML出力に反映。白基調の編集UI用CSSは出力ランタイムに含めない。
- 右側の「外観」は選択部品だけの文字色・背景色（現在のデザインの色トークン）に限定。全体デザインの変更は上部「デザイン」へ集約。色指定を戻しても状態・動作は変えない。
- 部品を選択し「部品」タブの「レイアウト」で配置を切り替え。映像/シーン/カメラプリセットは列数を変更（4×1、2×2、縦一列など）。音量は横/縦フェーダーを変更。選択肢の値とID、状態・ミュートの参照、イベント、条件は保持。必要な部品寸法を調整し、画面に収まらない変更は通知して拒否。横一列とグリッドを戻す際は行数に応じて高さも戻す。周囲の独立部品は自動で動かさない。
- 状態キーの選択は部品由来の日本語名・型・検索付き一覧に変更。長い既存キーは省略せず折り返して確認でき、参照するキー自体は変更しない。音量/ミュート/電源などは互換性のある型に絞る。状態定義の一覧にも名前を表示し、詳細で元キーを確認できる。
- 変更は既存のUndo/Redo・JSON保存/読込に統合。旧panel.props.responsiveは読み込めますが追従処理には使いません。旧版では追加フィールドが無視されます。

## 2026-11-13 編集・ボタンの簡単設定

- 基本の「サイズの一括設定」で、Ctrl選択した部品の幅・高さを一括適用。パネルを選ぶと音量部品の向きと幅・高さも一括指定できます。ロック、最小サイズ不足、画面外は全体を変更せず通知します。独立部品の位置は変更しません。必要なら配置機能を使って整列してください。
- 音声テンプレートは`panel.props.memberIds`に音量のIDを保持。旧パネルは初回一括操作時の完全内包音量を登録し、その後はパネル外に移動しても対象を維持します。ID参照は親子の幾何追従を意味しません。
- 普通のボタンを置き、基本の「押した感・スイッチング」で見た目だけ／押している間だけON／押すたびON・OFFを選択。通常時とON時の背景・文字色、長押し成立時間、グループ名、同時ON上限を指定できます。上限を越えると先にONにしたものからOFF。同じグループに異なる上限がある場合は最小値を使用します。
- 簡単設定は`button.props.simple`に保存し、状態キー入力は不要。実行中のON状態は表示中のボタンのみに保持し、プレビュー再開・ページ再表示でリセットします。複数ページをまたぐ永続状態や数値連動は従来の詳細設定を使用してください。長押しは既存と同じ進捗表示とキーボード用代替ボタンを備えます。
- 「詳細設定」を必要なときだけ開き、部品／動作／状態でページ遷移、状態キー、条件、イベント配列を編集。既存JSONは簡単設定を選ばない限り従来どおり。簡単設定を有効にしても既存イベント配列は保持し、通常クリックまたは長押し成立時に対応するイベントを実行します。
- 検証: 型検査、単体11件、既存4本＋新規1本のE2E（Linux Chromium）。一括変更・失敗時の無変更・Undo・JSON往復、旧追従パネル単独と明示選択移動、簡単設定の保存、グループ上限、押下中ONのポインター／キーボード、長押し、外部通信を遮断したHTML出力を確認。回収JS全体の型検査、実タッチ端末・Windows/macOSは未実施。
